# g50-pdf assets

- `background.ts`, `layout.ts`: generated by `node scripts/g50-overlay/build.mjs` (see that file). The background is the official G50 form rendered by LibreOffice from `public/templates/G50_template.xlsx` with the variable cells left empty; the layout says where each variable cell sits.
- `fonts.ts`: subsets (Latin, plus Arabic for DejaVu Sans) of Carlito (the metric-compatible stand-in for Calibri), Caladea (for Cambria) and DejaVu Sans, made with
  `pyftsubset <font>.ttf --unicodes="U+0020-007E,U+00A0-00FF,U+0152-0153,U+2010-2027,U+20AC[,U+0600-06FF,U+0750-077F,U+FB50-FDFF,U+FE70-FEFF,U+200C-200F]" --layout-features='*'`.
  Carlito and Caladea are SIL OFL 1.1; DejaVu Sans is under the Bitstream Vera / DejaVu free license. Redistribution with attribution is permitted.
